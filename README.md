# AI Language Translation Tool

## CodeAlpha Artificial Intelligence Internship - Task 1

This project is an AI Language Translation Tool developed using Python and Flask.

## Features

- Translate text between multiple languages
- English
- Hindi
- Kannada
- Telugu
- Tamil
- Malayalam
- Marathi
- Bengali
- Gujarati
- Punjabi
- Source and target language selection
- Swap languages option
- Copy translated text
- Clear text option
- Simple and responsive web interface

## Technologies Used

- Python
- Flask
- Deep Translator
- HTML
- CSS
- JavaScript
